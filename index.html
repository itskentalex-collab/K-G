    About

    KLIE is a private digital archive: memories, a timeline, collections and notes, built with plain HTML, CSS and JavaScript.

    KLIE AI is not a real AI model. It is a locally simulated assistant that picks from written responses and parses simple slash commands. It needs no internet, API or server.

    With cloud sync configured, the shared archive can appear across devices. KLIE AI remains a local simulation, not a hosted AI model.

    Nothing extraordinary. Yet worth remembering.
